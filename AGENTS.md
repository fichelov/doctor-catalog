# nutricare — «Приложение для врачей» (демо)

Статическое PWA: каталог детских смесей для медицинских специалистов. 24 карточки,
7 PDF-памяток, дерево подбора на 92 варианта. Публикуется на GitHub Pages из
**публичного** репозитория `fichelov/doctor-catalog`:
https://fichelov.github.io/doctor-catalog/

## Проверки (обязательны перед отчётом)

```powershell
npm.cmd run check     # синтаксис + целостность данных
```

По отдельности: `npm.cmd run lint` (синтаксис), `npm.cmd test` (данные).
Зависимостей нет — всё работает на голом Node.js, поэтому и CI не ставит пакеты.

- `tools/check-syntax.mjs` — парсит `js/app.js`, `js/data.js`, `sw.js`.
- `tools/test_data.js` — проверяет данные: 24 продукта с обложками, 7 памяток с PDF,
  валидные категории, ровно 92 листа дерева, каждый лист ведёт на существующий продукт.
- CI: `.github/workflows/ci.yml`, те же проверки на каждый пуш.

Если данные меняются намеренно (добавили продукт, изменили дерево) — **сначала**
обновить ожидания в `tools/test_data.js`, потом данные. Тест — это контракт.

## Структура

- `index.html`, `css/app.css`, `js/app.js`, `js/data.js`, `sw.js` — само приложение.
- `assets/covers/*.svg` — обложки продуктов (id совпадает с `NC.products[].id`).
- `assets/memos/*.pdf` — памятки; исходники — `assets/memos/_src/*.docx`.
- `manifest.webmanifest`, `icons/` — PWA.
- `tools/` — сборка и служебные скрипты:
  - `build_covers.py` — генерация обложек из данных;
  - `build_memos.py` — сборка PDF из DOCX-исходников;
  - `serve.py` — локальный сервер с brotli/gzip и чанковой выдачей PDF;
  - `gh_*.mjs` — вспомогательное для деплоя (токен только из `GH_TOKEN`, не хранить).

## Особенности публикации

- **`.nojekyll` обязателен**: без него GitHub Pages обрабатывает сайт через Jekyll
  и публикация ломается. Никогда не удалять этот файл.
- `*.br` и `*.gzip` — **генерируемые** сжатые копии для медленного туннеля.
  В репозиторий не попадают (есть в `.gitignore`), собираются скриптом сборки.
- `tunnel-url.txt` — одноразовая ссылка туннеля, в git не попадает.
- Деплой = `git push` в `main`. После пуша проверить, что сайт отвечает 200.

## Безопасность

Репозиторий **публичный**: всё, что попало в коммит, видят все. Демо-коды доступа и
тестовые логин/пароль опубликованы намеренно (это демо), но никаких настоящих ключей,
токенов и персональных данных в код не добавлять.

## Соглашения

- Приложение — ванильный JS без сборщика; новых зависимостей не добавлять без нужды.
- Текст для человека — по-русски. Комментарии в коде короткие и по делу.
- Правки в `js/app.js` (59 КБ, один файл) делать точечно и проверять `npm.cmd run lint`.
- Нетривиальные правки — на кросс-модельное ревью (см. `AGENTS.md` в корне воркспейса).
