# Приложение для врачей — демо

Каталог детских смесей для медицинских специалистов: закрытый доступ по коду,
ассортимент из 24 карточек, 7 PDF-памяток и «дерево решений» на 92 варианта перехода.

Демонстрационная версия — PWA. Соответствует ТЗ из PDF и уточнениям заказа на FL.ru
(одна кодовая база, восстановление пароля, защита персональных данных, бюджет 2027).

---

## Как открыть демо

**Ссылка (пока жив туннель):**

```
https://1675ef591ee867.lhr.life
```

Быстрый вход без регистрации:

```
https://1675ef591ee867.lhr.life/?demo=1#/home
```

**Демо-данные для обычного входа:**

| Что | Значение |
|---|---|
| Код доступа | `NTL-DOCTOR-2026` (есть также `NTL-CLINIC-0420`, `NTL-DEMO-0001`) |
| Логин / пароль | `doctor` / `doctor1234` |
| Код подтверждения email | показывается на экране (генерируется) |

### Установка на Android

1. Открыть ссылку в Chrome.
2. Меню ⋮ → **«Добавить на главный экран»** / **«Установить приложение»**.
3. Иконка появится на рабочем столе, приложение откроется без адресной строки.

На iPhone — Safari → «Поделиться» → «На экран "Домой"».

## Ограничения демо (важно)

1. **Туннель временный.** Ссылка `*.lhr.life` живёт, пока работает локальный сервер и
   SSH-сессия. Для показа клиенту — открывать в согласованное время. Для постоянной
   ссылки: развернуть архив на GitHub Pages / Netlify / Cloudflare Pages (бесплатно,
   3 минуты) или на хостинге компании.
2. **PDF отдаются по частям.** Туннель не пропускает файлы больше ~13 КБ, поэтому
   приложение загружает памятку 34 чанками по 4 КБ и собирает файл на устройстве.
   На обычном хостинге эта логика не нужна — достаточно прямых ссылок.
3. **Нет бэкенда.** Коды, письма, биометрия и push — демонстрационные. Реальные
   проверки появятся на этапе бэкенда вместе с 152-ФЗ/99-З и админкой.
4. **Контент шаблонный.** Названия, состав и характеристики — пример. Перед публикацией
   заменяются утверждёнными материалами компании.

## Постоянная ссылка вместо туннеля (рекомендуется)

Туннель нужен только для быстрого показа: бесплатный тариф рвёт сессию и меняет домен.
Для стабильной ссылки разверните статику на бесплатном хостинге (архив
`nutricare_demo_site.zip` в корне рабочей папки).

**GitHub Pages (5 минут, бесплатно, HTTPS):**

1. Создать репозиторий (публичный).
2. Распаковать архив и загрузить файлы в корень репозитория.
3. Settings → Pages → Source: «Deploy from a branch», branch `main`, папка `/ (root)`.
4. Через 1–2 минуты приложение доступно по адресу
   `https://<логин>.github.io/<репозиторий>/`.
5. Проверить: открыть ссылку на Android → «Установить приложение».

**Netlify:** перетащить папку на `app.netlify.com/drop` → ссылка сразу.

**Cloudflare Pages:** Create project → Upload assets → загрузить папку.

Особенности: все пути относительные, приложение работает из подпапки; PDF-ссылки
ведут на локальные файлы (чанковая загрузка нужна только для туннеля).

## Долгая жизнь туннеля (если хостинг пока не нужен)

- Запустить сторож: `powershell -ExecutionPolicy Bypass -File nutricare/tools/tunnel.ps1`.
  Скрипт сам поднимает сервер, перезапускает туннель при обрыве и пишет актуальный
  адрес в `nutricare/tunnel-url.txt`. Домен при перезапуске меняется.
- Запретить компьютеру засыпать: Параметры → Система → Питание → «Никогда».
- Стабильная сеть (кабель или Wi-Fi 5 ГГц), без VPN и энергосбережения адаптера.
- Клиентская страховка: после первого открытия service worker кэширует приложение —
  демо продолжит открываться даже при обрыве связи.
